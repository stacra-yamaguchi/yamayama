スコア設計

戦闘力は 5 特徴量の重み付き合成で算出し、レア度は各特徴量のオンライン z-score（セッション内母集団からの希少性）を基準に決定します。 

Power = 900 + 14500 * (
  0.24*Motion + 0.22*Silhouette + 0.20*Symmetry +
  0.18*HairComplexity + 0.16*ContourInvariant
) * ConfidenceBoost

Rarity = 0.60*mean(|z_i|) + 0.40*(0.5*HairComplexity + 0.5*ContourInvariant)
  • 輪郭不変量: Hu Moments (η20, η02, η11) の組を利用
  • 髪型複雑度: 頭部領域のエッジ密度 + 勾配方向エントロピー
  • 動作強度: ランドマーク速度（手首・膝・足首）の正規化平均
